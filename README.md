# Keyboard Macro 93

Keyboard Macro 93 is a powerful autoclicker built in Python, designed to automate mouse clicks with customizable intervals and conditions. This tool offers users the flexibility to improve productivity through repetitive click tasks, making it ideal for gaming, testing, and other tedious applications.

## Features

- **Customizable Click Intervals**: Set precise intervals between clicks, ranging from milliseconds to seconds, to suit any task.
- **Limit Click Count**: Configure a maximum number of clicks to perform, allowing for controlled automation without excessive clicking.
- **Hotkey Activation**: Start and stop the autoclicker with customizable keyboard shortcuts for easy access.
- **Cross-Platform Compatibility**: Run seamlessly on Windows, macOS, and Linux, making it accessible for a wide audience of users.

## Installation

To get started with Keyboard Macro 93, clone the repository and install the necessary dependencies. Use the following commands in your terminal:

```bash
git clone https://github.com/Developer/keyboard-macro-93.git
cd keyboard-macro-93
pip install -r requirements.txt
```

Make sure to have Python 3.x installed on your machine.

## Basic Usage Example

After installation, you can launch the autoclicker with a simple command. Here's a basic example to click every 0.5 seconds:

```bash
python autoclicker.py --interval 0.5 --clicks 100
```

Use the `--help` flag to see more options, including how to configure hotkeys and set a maximum click limit.
